## 1. 验收概述

### 1.1 验收目的

- 验证 FRD 系统满足合同与需求规格说明书（D02）的全部要求
- 验证系统达到上线部署方案（D10）的生产标准
- 验证系统通过合规审计（PCI-DSS / PIPL / 反洗钱法）
- 确认系统可正式交付客户使用
- 完成项目向运维的正式移交

### 1.2 验收范围

| 类别 | 范围 |
|------|------|
| 功能 | FRD-D02 全部需求项 |
| 性能 | 评分接口、查询接口、并发能力 |
| 安全 | OWASP Top 10、PCI-DSS、PIPL |
| 合规 | PCI-DSS v4.0、PIPL、反洗钱法、等保 2.0 三级 |
| 可靠性 | SLA、故障恢复、灾备 |
| 可观测性 | 监控、告警、日志、追踪 |
| 文档 | D01-D11 全套文档 |
| 运维 | 运维手册、应急预案、知识转移 |

### 1.3 验收依据

- 项目合同
- FRD-D01 项目立项报告
- FRD-D02 需求规格说明书
- FRD-D03 系统架构设计
- FRD-D04 数据库设计
- FRD-D05 API 接口规范
- FRD-D07 测试计划与测试报告
- FRD-D10 上线部署方案
- FRD-BASELINE-V1.1 跨文档修订基准
- PCI-DSS v4.0 标准
- PIPL（个人信息保护法）
- 反洗钱法
- GB/T 22239 等保 2.0 三级

## 2. 验收原则

### 2.1 核心原则

1. **以需求为基线**：所有验收项必须可追溯到 D02 需求规格说明书
2. **以证据为准绳**：每项验收必须提供客观证据（测试报告、日志、截图）
3. **零容忍硬约束**：PCI-DSS、PIPL、安全漏洞等硬约束 0 容忍
4. **分级分阶段**：按阶段逐步验收，每阶段达到标准方可进入下一阶段
5. **客户全程参与**：UAT 阶段客户必须深度参与并签字
6. **可追溯**：所有验收记录归档，可追溯到具体测试用例与执行结果

### 2.2 通过标准

| 验收项 | 通过标准 |
|--------|----------|
| P0 阻断缺陷 | 0 遗留 |
| P1 严重缺陷 | ≤ 2 遗留（必须有缓解措施与修复计划） |
| P2 一般缺陷 | ≤ 10 遗留（必须有修复计划） |
| P3 轻微缺陷 | ≤ 30 遗留（可后续修复） |
| 单元测试通过率 | ≥ 99% |
| 集成测试通过率 | ≥ 95% |
| 契约测试通过率 | 100%（或 ≥ 95% 且剩余有书面豁免） |
| E2E 测试通过率 | ≥ 95% |
| 行覆盖率（总体） | ≥ 85% |
| 行覆盖率（评分/规则引擎核心） | ≥ 90% |
| 行覆盖率（ML/GNN） | ≥ 75% |
| 性能 P99 | < 200ms |
| 安全高危漏洞 | 0 |
| 合规违反 | 0 |

> 缺陷遗留标准依据 FRD-BASELINE-V1.1 §2.2 统一执行。

## 4. 验收阶段划分

### 4.1 阶段全景

```
Phase 1: 内部验收（开发方自验）
   ↓
Phase 2: UAT 验收（客户参与）
   ↓
Phase 3: 上线前验收（生产部署前）
   ↓
Phase 4: 上线后验收（灰度 + 全量）
   ↓
Phase 5: 试运行验收（8 周观察期）
   ↓
Phase 6: 最终验收与移交
```

### 4.2 各阶段时间窗

| 阶段 | 起止时间 | 时长 | 责任人 | 对齐里程碑 |
|------|----------|------|--------|------------|
| Phase 1 | 2027-01-15 ~ 2027-01-30 | 16d | 测试负责人 | M6 RC（2027-01-31）前 |
| Phase 2 | 2027-02-01 ~ 2027-02-14 | 14d | 客户代表 + PM | UAT 覆盖客户深度测试 |
| Phase 3 | 2027-02-15 ~ 2027-02-22 | 8d | 技术负责人 + 安全 | M7 生产部署前 |
| Phase 4 | 2027-02-23 ~ 2027-02-28 | 6d | 运维负责人 | M7 生产部署（2027-02-28） |
| Phase 5 | 2027-03-01 ~ 2027-04-30 | 8 周 | 客户代表 + 全员 | M8 试运行验收 |
| Phase 6 | 2027-04-28 ~ 2027-04-30 | 3d | 验收委员会 | M8 最终验收（2027-04-30） |

> **UAT 时长说明**：Phase 2 UAT 统一为 14d（02-01 ~ 02-14），覆盖客户深度测试场景。D08 WBS §4.2 中 UAT（02-01 ~ 02-09，7d）需对应调整为 14d，同步修订 D08。

> 里程碑日期依据 FRD-BASELINE-V1.1 §5：M1 2026-08-15 ~ M8 2027-04-30。
