## 1. 项目概述

### 1.1 项目背景

中国支付产业年交易规模已突破 4000 万亿元（人民银行《2024 支付体系报告》），伴随交易量增长，欺诈交易规模同步攀升至 350 亿元/年。传统反欺诈方案面临三大瓶颈：

1. **规则引擎误报率高**：单一规则匹配误报率达 30%+，导致大量正常交易被拦截，影响用户体验
2. **新型欺诈识别滞后**：从欺诈模式出现到规则更新平均需 7-14 天，期间损失已成规模
3. **单模态漏检率高**：仅依赖交易金额/频率等结构化数据，无法识别基于社交工程/账号盗用的复合欺诈

本项目源于对 DWS（心理健康风险评估系统）多模态融合方法论的迁移探索：将「结构化 + 文本 + 行为」三模态融合架构应用到金融反欺诈场景，结合图神经网络（GNN）团伙检测，构建实时（P99 < 200ms）+ 离线（图分析）双层反欺诈引擎。

### 1.2 项目定位

**面向持牌金融机构（银行/支付公司/消费金融）+ 商户的实时反欺诈 SaaS 平台**，核心能力：

- 实时评分：单笔交易评分 P99 < 200ms，支持每秒 1000+ 笔交易
- 多模态融合：交易结构化 + 备注文本 + 行为时序 三模态加权
- 团伙检测：GNN 挖掘账户-商户-设备关联，识别洗钱链路
- 双轨设计：ML 引擎 + 规则引擎并行，规则兜底保证可解释性
- 合规内建：PCI-DSS 隔离区 + 反洗钱（AML）报告 + 数据保留 7 年

### 1.3 项目目标

### 2.1 行业现状

| 数据维度 | 数值 | 来源 |
|---|---|---|
| 中国年支付交易规模 | 4000 万亿元 | 人民银行 2024 |
| 年欺诈交易规模 | 350 亿元 | 国家反诈中心 2024 |
| 规则引擎平均误报率 | 30% | Gartner 2024 |
| 新型欺诈识别滞后 | 7-14 天 | 麦肯锡 2024 |
| 反欺诈市场规模 | 280 亿元 | 艾瑞 2025 |
| AI 反欺诈年增速 | 28.5% | IDC 2025 |

### 2.2 现有方案缺陷

| 方案类别 | 缺陷 |
|---|---|
| 规则引擎（FICO/SAF） | 误报高、规则维护成本高、无法识别新型欺诈 |
| 单模态 ML（仅交易） | 漏检团伙欺诈/社交工程欺诈 |
| 离线图分析 | 滞后性强（T+1），无法实时拦截 |
| 端云协同方案 | 终端算力受限，隐私合规复杂 |
| 海外方案（Featurespace）| 数据合规风险、本地化不足 |

### 2.3 用户痛点访谈结论（基于 3 家金融机构调研）

1. 87% 风控负责人表示「规则引擎误报导致大量客户投诉」
2. 78% 反欺诈团队反馈「新型欺诈识别滞后」
3. 65% 团队希望「图分析能力」但碍于实时性要求
4. 92% 客户要求「可解释性」（拒付附理由）
