## 1. 引言

### 1.1 目的

本说明书定义 FRD（金融反欺诈与交易风险预警系统）的功能、非功能需求与约束条件，作为设计、开发、测试、验收的基线。

### 1.2 范围

涵盖：用户认证、商户接入、交易实时评分、规则引擎、ML 模型治理、团伙图分析、案件管理、反洗钱报告、PCI-DSS 合规审计等全部功能。

不涵盖：支付清算、账户管理、信用卡发卡（由核心业务系统承担）。

### 1.3 术语表

| 术语 | 含义 |
|---|---|
| FRD | Fraud Risk Detection，本项目代号 |
| 风险分 | 0-100 分，越高欺诈概率越高 |
| 决策动作 | allow（放行）/ review（人工审核）/ block（拦截） |
| TPS | Transactions Per Second，每秒交易数 |
| GNN | Graph Neural Network，图神经网络 |
| Tokenization | 用 token 替代明文卡号 |
| PCI-DSS | Payment Card Industry Data Security Standard |
| AML | Anti-Money Laundering，反洗钱 |
| QSA | Qualified Security Assessor，PCI-DSS 评估师 |
| Chargeback | 拒付（持卡人对交易提出异议） |
| False Positive | 误报（正常交易被识别为欺诈） |

- FRD-D01 项目立项报告 V1.0

## 2. 总体描述

### 2.1 产品定位

FRD 是面向持牌金融机构 + 大型商户的实时反欺诈 SaaS 平台，通过「规则引擎 + 多模态 ML + GNN 团伙检测」三层防护，将欺诈识别延迟从 T+1 缩短至 200ms 内。

### 2.2 用户类别画像

| 角色 | 权限范围 | 关键诉求 |
|---|---|---|
| 风控分析师 | 案件处理 + 规则配置 + 申诉处理 | 高效处置 + 准确判断 |
| 风控经理 | 全公司风险概览 + 模型治理 + 报表 | 战略决策 + KPI 监控 |
| 商户管理员 | 本商户交易查询 + 申诉 | 接入便捷 + 透明可解释 |
| 合规官 | 审计日志 + AML 报告 + PCI-DSS | 合规可证明 |
| 系统管理员 | 系统配置 + Kill Switch + 模型治理 | 系统运维 + 紧急处置 |

### 2.3 运行环境

- 服务端：Linux x86_64 / Kubernetes 1.28+ / Python 3.12
- 客户端：现代浏览器（Chrome 110+ / Edge 110+ / Safari 16+）
- 部署：多可用区 + PCI-DSS 隔离区
- 集成：客户系统通过 REST API + Webhook + Kafka 接入

### 2.4 约束

- 多租户隔离：单实例支持多客户，PCI-DSS 强制物理或行级隔离
- 合规约束：PCI-DSS v4.0 + 反洗钱法 + 反电诈法
- 算法约束：模型不可使用种族/宗教/性别作为特征
- 实时约束：评分 P99 < 200ms（同步）/ 异步 Webhook 兜底
- 数据保留：交易 7 年、案件 10 年、审计日志 7 年
- 网络约束：持卡人数据环境（CDE）严格隔离

### 2.5 假设与依赖

- 假设：客户具备 API 网关，可转发交易流
- 依赖：OpenAI API（申诉文本分析）
- 依赖：阿里云 Kafka / OSS
- 依赖：Neo4j Enterprise（生产环境）

## 4. 非功能需求（NFR）

### 4.1 性能

| 指标 | 目标值 | 测量方法 |
|---|---|---|
| 同步评分延迟 P99 | < 200ms | Locust 压测 |
| 同步评分延迟 P999 | < 500ms | 同上 |
| 单实例 TPS | ≥ 1000 | 同上 |
| 集群 TPS | ≥ 10000 | 同上 |
| GNN 图查询 P99 | < 2s | Neo4j 监控 |
| Webhook 回调延迟 | < 5s | 端到端监控 |
| 批量评分吞吐 | ≥ 10000 笔/分钟 | Celery 监控 |
| 页面 LCP | < 2s | Lighthouse |

### 4.2 可用性

- SLA：99.95%（月度停机 < 22min）
- 多可用区双活部署
- 计划停机：每月 1 次维护窗口
- 故障恢复：RTO < 15min，RPO < 1min

### 4.3 安全性

- 传输加密：TLS 1.3
- 存储加密：数据库 TDE + 字段级 Fernet
- 卡号处理：Tokenization（不存储明文 PAN）
- 密码策略：长度 ≥ 14、90 天轮换、历史 5 次不可重用
- 限流：登录 5/min、API 1000/min/商户、评分 10000/min/商户
- OWASP Top10 + PCI-DSS v4.0 全覆盖
- 等保 2.0 三级

### 4.4 可维护性

- 代码覆盖率：≥ 80%
- MTTR：< 30min
- 文档完备：D01-D11 + A01-A04
- DWS 复用率：≥ 55%

### 4.5 可观测性

- 三支柱：Metrics / Logs / Traces
- 黄金信号：延迟/流量/错误/饱和度
- SLI/SLO：API 成功率 ≥ 99.95% / P99 < 200ms
- 业务指标：欺诈率/拦截率/误报率/案件数

### 4.6 合规

- PCI-DSS v4.0 通过 QSA 评估
- 等保 2.0 三级备案
- 反洗钱法 + 反电诈法合规
- 数据保留：交易 7 年、案件 10 年、审计 7 年
- 跨境数据传输评估（如适用）
